## What I Learned

### Evals

Even though models are non-deterministic Evals can handle this because they don't check for string match they test things like "does the model respond with harmful content rather than a specific sentence.

### Prompt Injection Protocol

Every model is different and trying to measure safety on one model can be totally different on the next so building your own protocol can help check cases more specific to your model and industry

### Principles Book

When reasoning models are thinking showing the user what the model is thinking makes for much better UI and gives the users an insight into the models thinking

### Tries

Used for things like autocorrect and a little different from a tree in each node can have up to 26 children per node where a binary tree can have up to 2 children per node
